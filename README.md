# 🚦 Smart Traffic Predictor

An AI-powered Smart Traffic Management and Prediction System built using Next.js, TypeScript, Tailwind CSS, and modern UI components.

🌐 Live Demo: https://smart-traffic-predictor.vercel.app/

---

# 📌 Features

- 🚗 Real-time traffic dashboard UI
- 📊 Traffic analytics visualization
- 🧠 AI-based congestion prediction interface
- 🗺️ Smart route recommendation system
- 🚨 Emergency alert panels
- 💬 AI traffic assistant chatbot
- 🌙 Modern dark-themed responsive UI
- ⚡ Fast performance with Next.js App Router

---

# 🛠️ Tech Stack

## Frontend
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## UI Components
- Radix UI
- Lucide React Icons
- Recharts

## Maps & Visualization
- Leaflet
- React Leaflet

## Deployment
- Vercel
